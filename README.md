# AAVARNIKA HOME AVENUE

Premium sofa fabric website with responsive collections, an interactive colour explorer, contact details, a map, and WhatsApp enquiries.

## Website

https://Vaibhav13Shukla.github.io/AAVARNIKA-HOME-AVENUE/

## Editing

- `index.html`: homepage, collections, colour explorer.
- `contact.html`: contact details, map, enquiry form, thank-you notification.
- Static HTML, CSS and JavaScript; no build step required.
- GitHub Pages publishes from `main`, repository root.

Fonts, GSAP, interior imagery and maps require an internet connection. Product texture visuals are illustrative. Enquiries open WhatsApp; customers must press Send there. Order availability, pricing and delivery are confirmed by the showroom.
